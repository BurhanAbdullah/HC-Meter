PRODUCT

Security context, not alert volume.

SYSWATCH is built around a local telemetry pipeline that helps an operator understand what changed, how signals relate and what evidence supports the interpretation.

Endpoint intelligence

Host identity, resources, interfaces, listening endpoints and bounded process intelligence.

Security posture

Firewall, Wi-Fi and SSH posture where the host exposes trustworthy telemetry; unavailable data remains unavailable.

Causal correlation

Normalized signals are related across a bounded temporal window to expose coherent behavioral chains.

Behavioral baseline

Local host context describes normal behavior and highlights deviations without autonomous remediation.

Evidence timeline

Events, severity, confidence and chain context remain inspectable by the operator.

Local-first boundary

The dashboard is localhost-bound by default and the current policy layer is read-only.

ARCHITECTURE

Observe → Correlate → Understand → Respond

Response is deliberately separated from observation and evidence. The current execution broker fails closed and has no default privileged adapter.

01
Observe

Host, process, filesystem and network telemetry.

02
Correlate

Normalize signals and evaluate temporal relationships.

03
Understand

Baseline context, causal evidence and policy evidence.

04
Respond

Privileged mutation remains disabled until the complete execution chain is validated.

SECURITY & PRIVACY

Conservative by design.

Local-first

The local console does not require a cloud account. The default API binding is loopback.

Least privilege

The packaged service uses a dedicated non-login account and an explicit writable state directory.

No destructive default

The current policy/evidence API does not execute containment, commands or host mutation.

Honest scope

Controlled synthetic tests are not evidence of universal real-world malware-detection accuracy.

STATUS

Release gate remains evidence-driven.

Engineering gates cover protected-state integrity and recovery, race and resource-bound testing, Debian install/upgrade/purge lifecycle, reproducible package builds, provenance ordering and security-contract checks. The remaining public gate is a real versioned release with its complete evidence chain, followed by the final audit and independent evaluation.
