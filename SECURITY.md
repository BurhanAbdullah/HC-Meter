# Security Policy

SYSWATCH is a local-first security monitoring framework. Privileged host mutation / real containment remains disabled by default and is not claimed as a production capability until its complete authorization, execution, rollback, audit, and adversarial validation chain is independently verified.

## Supported Versions

Until the first verified semantic-version release is published, the supported development target is the `main` branch. No versioned public release is currently claimed.

## Reporting Vulnerabilities

Please report security vulnerabilities responsibly through the repository's private vulnerability-reporting mechanism when available. If private reporting is unavailable, contact the maintainer privately before public disclosure.

Include, where safe to provide:

- description and security impact
- affected component or commit
- reproducible steps or proof of concept
- relevant logs or environment details with secrets and personal data removed

Do not publicly disclose or commit exploit details before coordinated disclosure.
